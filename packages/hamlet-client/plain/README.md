# The Hamlet

The small worked example for Storyletter: a village and the few people in it,
each with a trouble of their own. Seventeen cards across five decks, read in one
sitting.

## In the zip

- **`The Hamlet.html`**: double-click it to play. One file, with the Storylet
  Engine and the story inside it, so there is nothing to install and no server.
  It is the page Storyletter writes with **Publish ▸ Publish Playable HTML…**.
- **`the-hamlet.storylets`**: the project. Open it in Storyletter to see every
  card, when it is dealt, and what its outcomes change, then press **▶ Play**
  to deal it on the Board.

Storyletter also carries this project, under **Help ▸ Open an Example ▸ The
Hamlet**, so you can start from there too.
